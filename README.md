# NAPIWAS Observatory

## О проекте / токене

Токен NAPIWAS создан для того, чтобы каждый день хватало на пиво\! Мы не будем продавать всё сразу, нам нужно только чтобы каждый день хватало на пивас. Токен будет развиваться с помощью рекламы от компаний и производителей пива.

Самоописание из метаданных токена; заявления проекта не проверены независимо.

## Обсерватория

Основа: TON-Observatory-Template 1.3.0. Контракт:
`EQDOCUp_pDBvOmGRyEDE2bnCl2cjGmAWjPsTWRt_veSsfGSn` (9 знаков).

- Один автономный `index.html` для Resistance Tools / TON Storage: оформление, изображения, скрипты и сохранённый снимок встроены.
- RU/EN, операции, оценка капитализации, держатели 10 → 20, продавцы, сервисы, сжигания и торговые пулы.
- Изображение баннера и вместо флага предоставлено пользователем; источник и хеш оригинала сохранены в `project.json`.
- Лента сделок охватывает подтверждённые обмены прямой пары NAPIWAS/TON на STON.fi v2. Пара USDT/NAPIWAS показана в списке пулов; её сделки в общую ленту не входят.
- Капитализация — оценка по последней сделке основного пула × текущая эмиссия. Это не подтверждённая капитализация свободного обращения.
- История и проверки меток собираются постепенно. Непроверенные кошельки не получают вымышленных меток. База сервисов — Tonkeeper `accounts.json`.
- Для заморозки и стейкинга проверенные источники не настроены; интерфейс сообщает об этом.
- Внешние шрифты, скрипты и изображения для отображения не требуются. Загрузка свежего снимка и поиск кошелька используют сеть.

## Обновление

GitHub Actions: `.github/workflows/update.yml`, расписание `7,37 * * * *` (UTC), ручной запуск и запуск при изменении исходников. Выполнение по расписанию может задерживаться GitHub. Сбор сохраняет исправные разделы при недоступности источника.

```bash
python3 -m scripts.refresh_observatory
python3 build.py
python3 verify.py
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.cjs
```

HTML проверяет новый снимок из этого репозитория. Публикация файла в TON Storage / настройка DNS выполняются отдельно. Подключение к внешнему Cloudflare-планировщику не выполнено.
